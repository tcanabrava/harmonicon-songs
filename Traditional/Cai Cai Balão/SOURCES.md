# Cai Cai Balão

Plan ID: BR02. Research date: 2026-10-02.

Underlying melody: Anonymous traditional melody.

Melody reference: [Traditional melody reference](https://www.mamalisa.com/?t=es&p=2305). Traditional title cataloged under Domínio Público by [Discos do Brasil](https://discografia.discosdobrasil.com.br/compositor/dominio-publico). The catalog establishes the traditional attribution, rather than rights to any modern performer’s arrangement. This melody reference is used only for the underlying tune.

Adaptation: One complete melody pass, raised an octave to C5–A5. All rhythmic values doubled so sixteenths become slow eighth notes. This is the traditional children’s tune, not the distinct Assis Valente composition.

The chart uses a standard C Richter harmonica, 68 BPM, 2/4, C, single notes only, and no bends. A four-beat count-in precedes the first note; repeated passes have two beats of breathing space. Upper-register exercises need musical and physical play-through before release.

Reference editions, source MIDI performances, modern harmony, modern lyrics, recordings, and artwork are not included or licensed by this chart. No backing audio is supplied.
