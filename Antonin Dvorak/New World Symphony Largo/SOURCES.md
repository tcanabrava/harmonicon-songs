# New World Symphony Largo

Plan ID: CL04. Research date: 2026-10-03.

Underlying melody: Dvořák (1841–1904), Ninth Symphony (1893).

Melody reference: [Archived C-major Largo melody](https://trillian.mit.edu/~jc/music/abc/mirror/gulfweb.net:34043/~rlwalker/abc/largoc.abc). Reference ABC X:3004, first eight bars; composer melody only, not the later Going Home lyric adaptation or reference chords.

Adaptation: Opening eight bars of the English-horn theme, independently encoded in C and raised one octave from the reference. Later contrasting section omitted.

The chart uses a standard C Richter harmonica, 60 BPM, 4/4, C, single notes only, and no bends. A four-beat count-in precedes the first note; repeated passes have two beats of breathing space. Upper-register exercises need musical and physical play-through before release.

Reference editions, source MIDI performances, modern harmony, lyrics, recordings, and artwork are not included or licensed by this chart. No backing audio is supplied.
